新增频道视频列表与手动下载，整合到「Telegram 回源与频道」模块；同时统一 PikPak 账号管理页面及错误弹窗的显示风格。

- 添加指定 Telegram 频道，自动收录视频信息，支持扫描历史消息、分页查看、暂停和移除监控。
- 只收录列表，不自动下载。用户勾选后才将视频加入下载和 TelDrive 上传队列，沿用本模块的云端上传目录。
- 频道视频上传完成后清理服务器缓存，保留来源频道消息；复用磁盘空间预算、任务去重、上传断点和重启恢复。
- 修复断线期间大量新增消息的补扫、扫描失败回滚、Telegram 限流等待，以及设置停用和频道切换时的并发问题。
- 优化 PikPak 账号页面和错误弹窗，支持长文本、手机窄屏、键盘操作、错误重试及切换账号后的过期请求隔离。

### 已部署 Linux 服务更新

适用于 root 运行的 systemd 服务、项目内 `venv` 或 `.venv`，并且原服务正在运行。准备阶段至少需要 6 GiB 空闲空间；按实际部署修改目录和服务名。

```bash
curl -fL --retry 3 https://github.com/MengStar-L/TelDriveManager/releases/download/v1.2.0/update-linux.sh -o /tmp/tdm-update-v1.2.0.sh &&
sudo bash /tmp/tdm-update-v1.2.0.sh /opt/TelDriveManager teldrive-manager.service v1.2.0
```

更新保留配置、任务数据库、Telegram 会话、aria2 状态和下载缓存。失败原因会显示在脚本输出中；恢复锁和备份请保留。
