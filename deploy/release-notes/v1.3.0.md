新增 Telegram 频道自动同步：每个频道可关联独立的 TelDrive 文件夹，按指定起始时间补齐历史视频，并持续下载、上传新增视频。

- 保存目标文件夹和同步起始时间后，通过左侧频道按钮统一启动或暂停监控。时间按浏览器时区显示并转换为 UTC 保存，包含起始时刻发布的视频。
- 升级不会自动开启已有频道的自动同步。保存目录或时间不改变启停状态；暂停只停止后续自动提交，已入队任务继续执行。
- 手动选择下载保留，不受自动同步时间限制。频道任务在入队时固定上传目录，修改设置不改变已入队任务及其重试的目标位置。
- 自动同步分批提交，限制队列积压并公平处理多个频道；复用磁盘空间预算、断点续传和上传后临时文件清理。来源频道消息保留。
- 派发记录持久化，重启、清理已完成任务或移除后重新添加频道不会重复自动提交同一视频。补强时间边界、失败重试和设置切换期间的并发处理。
- 精简顶部工具栏，删除冗余说明和重复开关；文件夹与时间并排设置。桌面频道栏和视频列表延伸到底部，独立滚动并保留圆角；窄屏自动调整布局。

受保护视频能否下载仍取决于 Telegram 接口和当前账号权限。回归测试使用模拟媒体和隔离数据库，未以真实受保护频道验证下载。

### 已部署 Linux 服务更新

适用于 root 运行的 systemd 服务、项目内 `venv` 或 `.venv`，且原服务正在运行。准备阶段至少需要 6 GiB 空闲空间；请按实际部署修改目录和服务名。

```bash
curl -fL --retry 3 https://github.com/MengStar-L/TelDriveManager/releases/download/v1.3.0/update-linux.sh -o /tmp/tdm-update-v1.3.0.sh &&
sudo bash /tmp/tdm-update-v1.3.0.sh /opt/TelDriveManager teldrive-manager.service v1.3.0
```

更新保留配置、任务数据库、Telegram 会话、aria2 状态和下载缓存。失败原因会显示在脚本输出中；恢复锁和备份请保留。
